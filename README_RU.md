Обычно я работаю со всем продуктовым циклом: определяю логику, готовлю источники знаний, разрабатываю backend, подключаю модель, проверяю отказные сценарии и подготавливаю решение к развёртыванию.

## Основной фокус

- RAG-ассистенты и базы знаний по документам
- AI-чатботы и Telegram-боты
- Python и FastAPI backend для LLM-приложений
- OpenAI-compatible API, LangChain, FAISS и embeddings
- тестирование, оценка и контролируемое улучшение промптов
- обработка PDF, DOCX, OCR и извлечение структурированных данных
- API-интеграции, webhooks и автоматизация процессов
